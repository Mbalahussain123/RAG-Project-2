# PDF RAG Chatbot

## Project Description
This project uses RAG to answer questions from a PDF document.

## Technologies
- Python
- LangChain
- OpenAI
- FAISS
- RAG

## RAG Flow
PDF → Text Splitting → Embeddings → FAISS → Retrieval → LLM → Answer

## How to Run

pip install -r requirements.txt

python app.py
